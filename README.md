# Noco-Form

Noco-Form 是一个基于 `Vue3` 和 `Typescript` 开发的表单产品，作为一个<b>🟢 重前端</b>产品形态，表单编辑器和表单组件库所有代码完全开源。

#### 在线

[OnLine 在线预览](https://nocokit.github.io/noco-form)

![image](https://github.com/user-attachments/assets/8afe0a8b-3147-4769-8aa0-4077723b093b)



## ✨ 为什么选择 Noco-Form

- **使用简单**：拖拉拽的交互方式，降低上手成本
- **动态表单渲染**：轻松创建动态表单，所需配置极少。
- **完全开源**：表单编辑器核心代码完全开源，对表单研发拥有完全的自主权
- **扩展能力**：Noco-Form 提供了扩展能力，同时官方也提供低代码出码能力，无缝具备【无码】研发能力



## 📦 安装

通过 npm 或 yarn 安装 Noco-Form：

```bash
git clone git@github.com:nocokit/noco-form.git
cd noco-form
yarn
npm run dev
```
